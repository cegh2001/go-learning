# Ejercicios de Big O (Go)

Esta carpeta contiene ejercicios para practicar notación Big O en Go. Cada ejercicio tiene un archivo `*.go` con un `stub` y la descripción del objetivo. Intenta implementar las funciones respetando la complejidad objetivo.

Ejercicios incluidos:

- `ex1_constant.go` — O(1): Operación constante
- `ex2_logarithmic.go` — O(log n): Búsqueda binaria
- `ex3_linear.go` — O(n): Sumar o buscar en un slice
- `ex4_nlogn.go` — O(n log n): Usar sort y operar sobre datos
- `ex5_quadratic.go` — O(n^2): Doble bucle (matriz, comparación pareja)
- `ex6_exponential.go` — O(2^n): Subconjuntos por recursión

Cómo usar:
- Abre el archivo correspondiente y reemplaza los `TODO` por tu implementación.
- Si querés, puedo añadir soluciones en `other-class/solutions/` y tests de ejemplo.

Buena práctica: escribe comentarios sobre la complejidad de tu implementación y por qué cumple la cota solicitada.
