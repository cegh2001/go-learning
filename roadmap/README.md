# Roadmap de Entrenamiento en Go: De Fundamentos a Criterio Senior

Este espacio no es para copiar y pegar código ni para pedirle a una IA que resuelva las cosas. Es para desarrollar **criterio técnico real**, entender cómo piensa el compilador de Go, cómo gestiona la memoria y cómo auditar código con rigor.

## Reglas de Juego
1. **Vos escribís el código**: Acá el piloto sos vos. El tutor te guía, te cuestiona decisiones y te señala puntos ciegos.
2. **Cero magia**: Cada estructura y función debe justificarse en términos de complejidad temporal (Time Complexity), espacial (Space Complexity) y comportamiento en memoria (heap vs stack, allocations).
3. **Dos frentes por nivel**:
   - **Desafío Entrevista**: Algoritmia, estructuras de datos y comprensión profunda de tipos nativos.
   - **Desafío In-Situ**: Escenario laboral simulado (código preexistente que falla bajo carga, bugs sutiles o piezas faltantes).
